# Raw Audio Resources

## adhan_default.mp3

A **minimal placeholder** file is present for build compatibility.
Replace it with an actual Adhan MP3 audio file for real playback.

### Recommended
- Format: MP3 (high compatibility with Android MediaPlayer)
- Duration: 1–5 minutes (typical Adhan length)
- Source: Any Islamic audio provider or your own recording

### How to Replace
1. Obtain your preferred Adhan MP3 file
2. Place it at: `app/src/main/res/raw/adhan_default.mp3`
3. Rebuild the project
